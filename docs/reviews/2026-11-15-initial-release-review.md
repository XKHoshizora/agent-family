# 0.2 初版审阅与修复记录

审阅对象是同站点托管监督初版及独立 Matrix 人际聊天，不是完整 v9。开发和审阅使用真实 Claude Code CLI，指定 `claude-opus-5-5` 与 `xhigh`；回执核对了实际模型名称。Codex 负责集成、界面、部署和独立验收。没有向 Claude 提供业务数据库、密钥或线上环境变量。

| 问题 | 落实的处理 | 验证位置 |
| --- | --- | --- |
| 未配置服务也能被批准，之后补建服务会改变消息目的地 | Agent 与提议验证真实模型服务；快照冻结 URL 和协议；运行时严格比对；旧缺失快照必须重新审批；开放群引用的服务不能被原地替换 | family.test.ts、family-integration.test.ts |
| 主人被降为只读后失去停止权 | 保留拒绝、暂停、归档、屏蔽、解除关系、停用自己 Agent 和取消任务；角色降低使群暂停；不授予创建、批准或恢复权 | 同上及线上角色降低回归 |
| 归档入口错误跳到其他房间 | 专门保留从 Family 打开的房间选择，包括刷新；仍使用服务端主人 ACL，输入关闭 | 浏览器归档回归 |
| 监督群挤占普通群名额 | 普通群额度排除监督群；监督群按每个必要主人检查活跃与暂停群上限 | 单元/集成测试 |
| 管理员审计能推断私有屏蔽原因 | 管理员常规审计列表排除 family.* 控制事件；私有原因不发给其他主人 | 集成测试 |
| 昵称可改或重名 | 使用账户当前名称，配合随机且持久的空间成员编号；同名明确提示 | 单元测试及界面核对 |
| 快照哈希可能用于猜测私有职责 | 每群独立服务端盐值，不向客户端输出；增量迁移旧快照 | 单元测试 |
| “完整记录”与默认 300 条页面不一致 | 增加受同一房间 ACL 保护的稳定游标分页；旧页只读；导出上限明确披露 | 605 条真实数据库记录分页测试及浏览器回归 |

完整验收数量及线上部署记录见 [ACCEPTANCE](../ACCEPTANCE.md)。原始 Claude 执行结果、会话材料和测试账户保存在 Git 排除的本地目录，本文件只记录去敏结论。

未纳入首版：跨服务器 Agent 自动运行、端到端加密的主人监督证明、工具或电脑跨主人授权、Cua 执行、72 小时连续观察，以及 Matrix 异地灾备。独立 Element 的加密聊天验证不能替代这些验收。
