# 统一聊天入口：复核与验收

本批次提供 Element 内的联系人和自己的 Agent 管理；不是 v9 全部监督群功能验收。正式交付状态另见发布记录。

## 实际复用

- Element Web 1.12.35 原生消息、房间、附件、设备与恢复 UI；公开 Module API 2.3 添加侧栏及页面，未重造聊天界面、同步或浏览器密码库。
- Synapse 1.165.0 官方 OIDC 登录；Better Auth / OAuth Provider 1.7.25 官方协议实现，PKCE + 固定回调 + RS256；不可变用户 ID 映射原有 Matrix ID。
- Element 维护的 `@vector-im/matrix-bot-sdk` 0.11.0-element.0 及其 Rust 加密存储；Agent 独立账号、持久设备、加密房间、同步与发送均由 SDK 完成。
- 模型请求沿用 AI SDK；仅复用经本批测试覆盖的现有鉴权、模型配置与持久化。AF 自有关系和监督代码不因存在就被认定完成。

## Claude Code 复核落实

使用 Opus 5.5、xhigh；附三份执行回执，均模型核验成功。原始审阅是修复前快照。

1. 模型空间成员被撤销或降为 viewer：调用前和发布前重新核验，拒绝后续执行。
2. 编辑按 Agent 实际工作空间校验模型和角色，而非 UI 默认空间；自己的 Agent 仍可暂停。
3. 发布前先等待成员检查，再同步核对 generation/状态/取消信号；暂停等待已发起提交结束。恢复完成使用 generation 条件写，避免覆盖后来暂停。已被 Matrix 接受的消息仍可能因网络延迟稍后送达。
4. 启动失败不覆盖持久暂停状态；聊天或显式重试可重连。尚无自动指数退避重试。
5. 接入失败保留独立身份并提供重试，不因失败无限创建身份。临时 provisioning 密码加密保存到成功接入后清除；未采用审阅中立即删除密码导致无法重试的建议。
6. 主人离开房间后再次点聊天会重新邀请；创建序列化；Agent 已不在旧房间则新建受限房间。
7. SDK 数组过滤实际会合并多次查询，因此原“仅返回第一类成员”的推测不成立；仍改为一次完整成员快照，明确拒绝任何第三方 join/invite/knock。
8. AF 拉黑先阻止新申请，再同步 Matrix ignored-user list；同步失败保留错误并重试。原生 Ignore 的已知关系在联系人加载时同步。解除拉黑不恢复好友；共同群不会自动解散。跨设备并发更新不作为强一致协议验收。
9. Nginx 每个覆盖 add_header 的 location 明确提供防跨站嵌入和 nosniff；同源主页嵌入允许。
10. 公共代理仍可能聚合请求 IP；保留限流，未以不可信请求头绕过。当前小规模试用，未完成多人负载验收。
11. 忙碌消息收到“本条未执行”通知，不静默排队或自动重试。
12. 恢复先初始化运行器再提交 active；失败显示可重试状态。

实测另修复：v12 房间创建者具有隐式权限，不能再次列入 users；固定 room_version=12、只显式列主人。参见 [Matrix v12](https://spec.matrix.org/latest/rooms/v12/)。Rust SDK 的 SQLite 类型为编译期枚举，运行时使用锁定版本约定值。

## 已验证

- 272 项单元/接口测试通过；生产构建通过。
- 原工作台 21 项浏览器回归通过（本批改动前后对应认证和接口构建；后续 CI 重新执行）。
- 隔离 Railway：Alice/Bob 同一 AF 登录映射 Matrix；好友申请、接受、双方列表；拉黑阻止重新申请且双方移除关系；解除不恢复好友。
- 隔离 Railway：Agent 独立身份、原生加密私聊；网络发送载荷为 ciphertext、无测试正文；主人收到并解密回复。
- 暂停无回复；恢复只处理新消息、不补跑暂停期间消息；刷新保留加密历史；后端重启后同设备继续加密回复。
- 临时测试使用明确标记的合成模型，不把它当作真实 LLM 验收。没有向临时后端传输本地模型密钥。
- 备份 v2 包含 Agent 同步及 Rust 加密存储，8 项备份/恢复测试通过；恢复要求空目录，保留 v1 兼容。多文件并非全局原子快照，灾备需停止运行器，详见 unified-backup。

## 明确未交付

跨服务器的 AF 好友申请协议、Agent 对 Agent 好友/聊天、跨主人 Agent 群监督、电脑和工具执行、附件理解、Agent 设备人工 SAS 验证、跨设备密钥恢复演练、规模负载测试。普通 Matrix 联邦和人类群聊仍由原生功能提供，不能等同于上述 Agent 规则已完成。

每人最多 10 个 Agent，每 Agent 每 UTC 日最多 20 次尝试，无自动重试。短期模型上下文仅在进程内保存，暂停/重启后清空；聊天记录由 Matrix 保存。模型服务会收到授权主人本次文字及有限上下文，不应把 E2EE 理解为模型提供商看不到输入。
