# 工具循环怎么设上限，以及别的产品为什么不用另外绑定就能用工具（调查记录）

日期：2026-11-19。用途：第 2 批（只读工具）的设计依据。来源是官方文档和官方仓库的源代码；标“未核实”的没能确认。Codex 那一行只看到了搜索摘要和问题列表，是最弱的一条。

## 一次回复里的工具循环，各家怎么设限

| 产品 | 限制的是什么 | 默认值 | 到上限时 |
|---|---|---|---|
| Claude Agent SDK | 模型轮数；花费（美元） | 都没有默认值，由开发者设 | 返回一个错误结果，没有最终回答；可以提高上限后继续 |
| OpenAI Agents SDK | 模型调用次数 | 10 | 抛异常，或由处理函数给出一个最终回答 |
| Codex CLI | 没找到上限 | — | 问题列表里说没有循环检测 |
| Hermes Agent | 每个用户回合的模型迭代数；单个工具的次数；重复调用检测 | 500（旧版 90）；搜索 50 次 | 停下并总结，提示“发送 continue 继续” |
| Cherry Studio | 步数 | 20（用户可调 1–100） | 循环直接停止 |
| LangGraph | 步数 | 10007 | 抛异常 |
| Vercel AI SDK | 步数 | 20 | 停止并记一条警告 |
| LiveKit | 工具步数 | 3 | 关掉工具再调用一次模型，让它用已有的信息作答 |
| xAI | 轮数 | 有全局上限 | 用已收集到的内容生成最终回答 |

重复调用的检测：Hermes 在“同一个工具、同样的参数、同样的结果”连续 3 次时给提示，5 次时可以强制停止；同一个调用连续失败 2 次警告、5 次拦截。DeepSeek Harness 的阈值是 3、5、8。

Anthropic 的工程文章只说“通常要有停止条件，比如最大迭代次数”，没有给数字。

## 为什么不用另外绑定就能用工具

| 产品 | 不需要密钥的工具，以及怎么做到 | 需要密钥的 |
|---|---|---|
| Cherry Studio（AGPL-3.0，另售商业许可） | 默认搜索走 Exa 的公共 MCP 服务（不用密钥）；读网页、读本地文件、Python、记忆都是在本机执行；默认优先用模型服务商自带的搜索。早期版本有“在本机加载谷歌、必应、百度结果页”的本地搜索，据其问题列表正在移除（是否已移除未核实） | Tavily、博查、智谱、Exa 接口、Firecrawl、Jina、Brave |
| Hermes Agent（MIT） | 文件、终端、执行代码、记忆、搜索历史会话、待办；搜索可用不需密钥的 DuckDuckGo，或轮流使用几家的公共免费额度 | 生成图片、搜 X、远程沙箱；搜索密钥是可选的 |
| DeepSeek Harness，即 `dsh`（MIT，deepseek-ai，2026-08-13 发布，开发者预览） | 命令行、文件、读网页（普通 HTTP） | 搜索（用 DeepSeek 的密钥，默认最多 5 次） |

要点：这三个都是装在用户自己电脑上的程序，工具在用户的机器上跑、用用户自己的网络，所以大部分不需要另外的密钥。我们是网站，工具在我们的服务器上跑；只碰我们自己数据的工具（搜历史、查时间、读文件）同样不需要任何密钥，上网搜索则需要正规的搜索服务或服务商自带的搜索。

## 对我们的设计的结论

1. 主要的上限按“模型轮数”算。聊天产品取小的数：LiveKit 3，Agents SDK 10，Cherry Studio 和 Vercel 20。Hermes 的 500 是写代码的 Agent 用的值。
2. 到上限时不要报错或没有回答：关掉工具再调用一次模型，让它用已经查到的内容作答。
3. 加重复调用检测：同一个工具、同样的参数连续出现时，先在工具结果里告诉模型“不要重复”，再次出现就拦截。
4. 另设一个按花费或时间的上限，轮数本身不能限制单次回复的总花费。
5. 每个工具单独的次数上限（例如搜索）。
