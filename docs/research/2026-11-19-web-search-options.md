# 上网搜索的可选方案（调查记录）

日期：2026-11-19。用途：路线里“第 2 批和第 3 批之间的上网搜索小批次”的设计依据。来源都是官方文档和价格页，读取日期 2026-11-19；标“未核实”的是没能从官方来源确认的。**价格和功能变得很快，动手前要重查。**

## 路线 A：模型服务商自带的工具

| 服务商 | 怎么开 | 价格 | 能不能拿到网页正文 | 能限制域名吗 | 备注 |
|---|---|---|---|---|---|
| Anthropic | `tools` 里加 `web_search_*` / `web_fetch_*` | 搜索每 1000 次 10 美元，另加 token；读网页不另收费 | 搜索：正文是加密的，我们看不到；读网页：返回全文 | 能（允许/禁止域名、最多次数、大致位置） | 返回它实际搜的词和引用（最多 150 字符）。读网页只能读对话里已出现过的链接 |
| OpenAI | Responses 接口的 `web_search` | 每 1000 次 10 美元，另加 token | 只有来源和标注，没有原文 | 能（最多 100 个域名） | Chat Completions 接口只有专门的搜索模型，功能少 |
| DeepSeek | `deepseek_web_search` / `deepseek_read_url`（三种接口都支持） | 2026-11-18 起搜索和读链接本身不收费，只收 token | 只有摘要；读链接的正文是加密的 | 不能 | 文档只写了 `deepseek-flash`；chat-demo 用的就是这两个工具 |
| Google Gemini | `google_search` 工具 | 每月 5000 次免费，之后每 1000 次 14 美元 | 引用和“搜索建议”的 HTML | 未核实 | |

共同点：搜索词直接到服务商和它背后的搜索引擎；网页正文在模型读之前我们过滤不了；这些工具能不能经过 OpenAI 兼容的中转渠道，没有任何官方文档说明（未核实）。

|---|---|---|---|---|

| Serper（Google 结果） | 0.30–1.00 美元 | 2500 次 | 只有摘要 | 无 |
| Brave | 4–5 美元 | 每月 5 美元额度 | 摘要，或给模型用的片段 | 未见 |
| Exa | 4–12 美元 | 每月 10 美元额度 | 正文或要点（每 1000 页另收 1 美元） | 有 |
| Tavily | 约 8 美元 | 每月 1000 次 | 摘要，可选正文 | 有 |
| SerpAPI | 约 7.25 美元起 | 每月 250 次 | 搜索结果页 | 无 |

| 博查 | 未核实 | 未核实 | 摘要、可选总结；能限制域名 | 未核实 |

各家对中文和日语搜索质量都没有官方说法（全部未核实），要用我们自己的问题实测。

## 官方对“网页里藏指令”的建议

- Anthropic：告诉模型搜索和工具返回的内容是不可信的资料；用 JSON 包起来；不要把自己的指令放进工具结果；最小权限和沙箱；在模型行动前筛查工具输出；专门做注入测试。
- OpenAI：提示词里写清规则和例子；公开网页搜索和私有数据查询分成不同的请求。
- DeepSeek：请求里有 `safety_check: {level: "high"}`，它过滤什么未核实。

## 对设计影响最大的五点

1. DeepSeek 的搜索和读链接是公开的接口功能，调用本身免费，但不能限制域名，也拿不到正文。
2. Anthropic 和 OpenAI 的自带搜索，搜索词和网页正文都不经过我们，我们既看不到也过滤不了。
3. DeepSeek Search 接口是路线 B 里最便宜的，带中文语言参数，搜索词上限 128 个字符。
4. Bing 的普通搜索接口已经没有了。
5. 自带工具能否经过中转渠道没有文档说明；路线 B 对任何模型都能用，是唯一不依赖中转的。

## 初步倾向（待和用户谈）

- 默认用路线 B：搜索词经过我们的检查（保险箱内容不出站），网页正文先清洗再给模型，对所有模型都可用。站点自带一家搜索服务，用户也可以像配置模型提供商那样填自己的。
- 路线 A 作为每个 Agent 可选的开关，只在所用模型的服务商支持时出现，并向主人说明“搜了什么我们不经手”。
