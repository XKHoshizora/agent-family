# 自由讨论设计与实施计划

用户授权直接判断、实现、测试后发布。采用顺序接话，复用现有模型适配、工具权限、额度、SSE 与 LINE，不新增收费主持模型。固定轮询不能真正交棒；额外主持模型增加成本和故障面，均不作为本次方案。

## 行为

- 新模式 free：所有启用伙伴参与，用户点名决定首位；每次只一位发言。AI 用内部 discussion_turn 工具表达交棒、继续或无补充；正文开头的有效 @名字作为兼容后备。只接受本次参与者，不能授权资料工具或改变限额。
- 点名优先下一位；连续定向对话不能饿死其他人，超过参与人数次未发言的伙伴获得优先机会。无交棒时选最久未发言者。每参与人数次发言计一轮（包括失败位次），默认 3 轮，支持 null 不限轮数。
- 单次模型调用上限默认 30，必须有限；轮数与调用上限可在运行中修改，下一次发言／模型调用前生效，已发送请求不追回。空间每日与 LINE 子额度继续生效。每次发言只预留其最大步骤，未用释放，不预占无限讨论的所有额度。调用归属开始日。
- 可选全部伙伴无补充时结束（默认开）；连续三次重复或失败强制结束；用户停止、权限撤销、额度不足、达到轮数均结束并显示原因。模型不能用一次结束信号替所有成员结束。重启标记中断，不自动恢复收费请求。
- 上下文始终保留用户问题，优先每位伙伴最新有效发言，再装近期过程，含明确截断标记；工具返回与系统提示仍独立于 48,000 字符对话预算。
- Web 显示发言轮次、接话关系、运行进度、额度及可修改设置。LINE 可设置默认自由讨论及限额，/af 停止、/af 轮数 N 或 无限制、/af 额度 N、/af 状态只控制本绑定发起的运行；结果结束时发送最近四条完整发言与结束原因，避免逐条刷屏。

## 实施与验证

1. 增量表字段、共享设置校验、顺序选择与预算调整；保持旧三种模式语义。
2. 自由讨论执行器、上下文、控制工具与权限检查；运行设置 API。
3. Web 设置与进度、LINE 默认设置和控制指令。
4. 回归：真实 SDK 模拟交棒、五位公平参与、无限轮数、动态改限、额度竞争、重复／无补充／失败／停止／撤权、重启与旧数据库迁移；桌面和手机浏览器。
5. 构建通过、备份、发布特定版本、线上只读检查；尽量补充有界真实模型验证，单独说明真实 LINE 尚未绑定。

范围自检：不新增模型执行权限，不实施主持总结、并行自由接话或自动重启任务。不限轮数不等于无限费用；至少两位启用伙伴才能自由讨论。
