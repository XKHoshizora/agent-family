# 对话阅读调整

用户明确要求用户气泡靠右，并整理模型返回的思考内容。沿用既有界面和用户授权的自主实现范围，本次不扩展到 Claude 审查中的调度、预算、总结或 LINE 权限改造。

- 用户角色的消息靠右、头像在右，保留作者和时间；Agent 回答仍靠左。窄屏保持可读宽度。
- 模型明确返回的 reasoning 流与正式回答分开存储，默认折叠，允许键盘展开。未返回的内部思考不推断、不补写。
- 兼容已有消息开头或独立行上的 `<think>` / `<thinking>` 块；流式未闭合块也不混入正文。代码块中的标签示例保留。
- 正式回答用于复制、存为笔记、后续群聊上下文和 LINE 正文；JSON 导出保留独立思考字段。旧记录通过读取兼容，不批量改写历史。
- 思考区展开后限制高度并内部滚动；无思考字段不显示空面板，流式／停止／失败不显示虚假的“仍在思考”。

验证：解析边界与分片、SDK 原生思考流及数据库往返、旧消息兼容与后续上下文、桌面／手机左右对齐与折叠展开、复制／笔记正文、生产构建。使用隔离测试数据，不调用付费模型验证排版。
