# 自由讨论质量与交付

用户授权直接修复、复杂话题验收并发布。复用现有单进程运行、权限、上下文、额度与取消机制；不增加独立主持模型或无限重试。

选择：纯提示词不能修复调度和失败丢失；每轮另加主持模型会增加延迟与费用。采用程序负责阶段、失败与预算，现有参与者负责短发言和最终整理。

- 普通发言只回应一个问题并增加一项意见，目标 120–250 中文字，不重写整套清单。首位先明确目标与视角；存在关键歧义时以 clarify 动作提出一个问题并等待用户，避免猜测后继续收费。
- 所有发言的状态、完成原因、有限正文进入本次上下文。错误片段明确未完成且未经复核，不作为共识；思考不转发给伙伴。连续两次失败的伙伴暂时跳过，用户再次点名可以重新尝试。
- 交棒问题仅保存在结构化字段中，正文有内容时不再重复追加；界面接话关系可查看问题。相似文本检测结合数值／否定变化保护，模型也被要求无新内容时 pass。检测不等同于完整语义理解。
- 普通工具步骤留出最后一次调用；最后一个可用发言位用于最终整理，计入原轮数和额度。提前达成结论、全员无补充、重复时进入整理。最后阶段不提供工具，不再发起交棒。输入插话仍可让出当前请求，次数不重置。
- 最终整理列出目标与假设、可执行方案、已确认依据／分歧、待确认事项与下一步。失败信息必须明确，不能把未完成意见写成全员共识。无法调用、取消、撤权或整理失败时提供无额外模型调用的结束记录，明确尚无完整最终方案，不把摘录伪装成总结。
- Claude 使用独立思考加正文预算，配合短任务而非单纯放大所有请求。MiniMax 思考保持启用。无自动追加收费重试，模型与任务额度均保持有限。

验证：确定性测试覆盖失败传递／暂停、重复问题、近似重复与数值更正保护、预算预留、最终阶段权限／工具、插话和取消竞争、最终失败降级、LINE 回传；浏览器验证标记和问题卡片。真实测试仅使用新建合成话题，包含多因素计算、需求歧义、可控故障后由真实模型接话；不重放用户私聊。发布前检查空闲、备份，发布后核对固定版本和新合成调用。
