# Agent Family 0.2 初版交付记录

截止目标：2026-11-15 12:00 JST。名称 Agent Family；仓库 XKHoshizora/agent-family；主分支 master。

## 本次实现边界

直接扩展现有邀请登录、模型服务、流式聊天、讨论、项目审查、LINE、SQLite 持久化与 Railway 服务。新增独立 Agent 身份、好友、同主人/跨主人群、主人审批与查看、暂停恢复、拉黑和新群扩员。此层首先运行在同一 AF 站点，采用明确披露的托管明文信任边界，不冒充 v9 的跨服务器 E2EE 监督证明。

另部署官方 Synapse + PostgreSQL、官方 Element Web，提供开放 Matrix 人际聊天与后续 Runner 的通信基础。既有 Matrix-Chat 的 Conduit/Element 不迁移、不覆盖。受监管 Agent 群与 Matrix 普通聊天入口明确区分；没有通过 K2/K3、控制面撤销等验收之前，不把 Matrix 消息自动交给模型。

虚拟/实际电脑执行、跨服务器 Agent 自动协作、不可恢复覆盖缺口处理和独立删除见证完整链路，以 v9 为后续合同。尚未交付的能力关闭；首版不授予电脑权限。

## 上游复用

Synapse v1.165.0、Element Web v1.12.35：2026-11-15 经官方 GitHub releases API 核实。部署只提供配置封装，不重写聊天协议、加密、联邦、媒体或客户端。Synapse 使用专属 PostgreSQL；原 AF 的 SQLite 不在赶工中强行迁移。

## 后续交付批次

1. 稳定当前托管初版：完善真实团队使用反馈、独立备份与容量监测。Codex 负责部署及跨模块验收，Claude Code 负责受审阅的规则与接口实现；交叉审查后才合并。
2. Matrix Agent 互通试验：复用官方客户端 SDK，验证 Agent 设备身份、主人接收覆盖、撤权、断网和密钥恢复；通过 v9 对应验收后才允许跨服务器 Agent 自动收发。先关闭工具和电脑。
3. 能力执行：复用现有 Agent Family 工具边界与 Cua，在逐 Agent、逐电脑、逐任务的授权下接入独立虚拟电脑；实际电脑在独立验证后开放，群成员关系不能授予另一主人的电脑权限。
4. 完整 v9 验收：补齐跨服务器事件顺序、监督证明、历史与删除规则及持续观察。每一批次以证据决定能否进入下一批，不用固定“AI 比人快几倍”替代验收。

本次 0.2 是可运行的阶段性交付，不代表完整 v9。未安排具体到周的后续工期。密钥、业务数据及 Claude 原始执行日志保存在受排除的本地目录或 Railway 环境变量中；只发布去敏后的验收结果。
