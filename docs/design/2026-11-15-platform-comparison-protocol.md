# 聊天底座实测协议

状态：本轮验证与选型已完成，逐项通过及未验证范围见 [实际验证报告](../reviews/2026-11-15-platform-comparison/README.md)。选型不等于全部产品能力已实现。

用户要求：深入验证 OpenIM、HuLa、Element＋Synapse；保留开放互通、跨主人 Agent 群与主人可见。Agent Family 现有实现没有优先保留权。

## 必须区分的证据

- D：官方文档声称；S：固定源码中的实现；R：本次真实运行验证；U：未验证或受阻。
- 能启动不能算功能通过；单服务器多账号不能算联邦；管理员读取数据库不能算主人可见。
- 通过受控脚本调用真实账号属于协议/API 验证，不等于完整 Agent 产品或模型集成验收。
- 原生能力、简单配置、适配开发、新增服务与未知成本分开记录。

## 同一组场景

1. 两个不同主人、各自独立 Agent 账号，另有无关第三人。
2. 人与人、人和 Agent、同主人和跨主人 Agent 私聊。
3. 跨主人 Agent 群：两位主人能读到原消息和附件；第三人不能读。
4. 普通好友申请、接受、拒绝、删除、拉黑及其群内语义。
5. 群扩员与退出：新成员不能读取未授权历史；退出后不能收到新消息。
6. 暂停与恢复：证明通信权限与执行权限的差异，不把禁言直接算成停止正在运行的任务。
7. 断线、重登、多设备与历史同步。
8. 两个独立服务器之间的身份、邀请、群成员、消息与附件互通；兼容第三方客户端。
9. 加密房间及主人设备的真实解密；密钥未就绪时不得声称已满足可见性。
10. 部署可重复性、许可证、依赖数量、维护状态、更新路径与改造边界。

## 实验边界

- 隔离测试目录与合成账号；不导入业务数据和线上密钥。
- 不直接运行上游含 Docker socket、SSH 私钥或广泛宿主机挂载的完整示例。
- 测试服务优先只监听本机；无需公开注册或线上迁移。
- 保留精确提交版本、运行命令、脱敏结果和失败记录。
- 不能完成的场景明确标记 U，不通过降低用户要求来选型。

## 选型门槛

开放互通为必须项。跨主人群与主人可见必须有可实施、可验证的方案；不能用“服务端能看见明文”冒充加密场景的主人监督。优先复用现成客户端、消息存储、同步和加密，AF 只保留经比较后仍有必要的部分。

选型确定后按小批次推进：先把真实社交客户端作为主入口，再实现 Agent 与主人授权扩展；每批分别记录测试、上线和剩余限制。
