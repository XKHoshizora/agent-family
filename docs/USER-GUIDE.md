# 使用与 LINE 接入

## 多伙伴聊天

名字、职责、模型分别配置。可以用同一个模型扮演不同岗位，也可以混用 GPT、Claude、Gemini。每条回答显示配置的实际模型名。读取到服务商模型列表不等于真实调用成功。

- **各自回答**：伙伴看同一个问题分别回答，最多三位并发。
- **一起讨论**：第一轮提出观点，第二轮阅读第一轮结果并回应，最多两轮。
- **自由讨论**：所有启用伙伴逐个发言，用户点名决定首位。伙伴可以向另一位提问并交棒；没有明确交棒时轮到最久未发言者，等待过久的伙伴也会获得机会。每次能看到此前刚完成的发言。
- **指定一位**：选择一位伙伴；也可输入 `@小文`，后加空格或标点。
- 正文点名优先于下拉默认对象；单人模式同时点多位会提示切换模式。讨论只选中一位时自动改为单轮，第一轮不足两份有效回答时结束，失败伙伴不进入第二轮。
- **停止**：取消生成，阻止后续轮次与工具写入。已发给模型的请求可能仍计费。

Enter 发送，Shift + Enter 换行；中文输入法选字不会误发。未发送文字仅保存在当前浏览器会话，退出登录清除。附件支持文本和代码，作为消息发给模型；不解析图片、PDF、音视频。启用工具的伙伴可按需读取本群笔记；没有任意浏览网页或读取电脑文件的能力。

用户消息在右侧，AI 伙伴的回答在左侧。模型明确返回的思考内容放在「思考内容」里，默认折叠，点击或用键盘展开；正式回答直接显示。没有返回思考内容的模型不显示空面板，系统不会推测或补写隐藏的内部思考。

兼容历史回复中开头或独立行的 `<think>` / `<thinking>` 块，代码示例中的标签保留原样。复制回答、存为笔记、后续对话上下文和 LINE 正文使用正式回答；JSON 导出保留独立的思考字段。此前未接收或未保存的思考内容无法恢复。

发送前会显示模型调用范围并预留最大次数（有工具每位每轮最多三次，无工具一次）。未使用部分在完成、失败、停止或重启后释放；已经发起的请求仍计入用量。多个群不能抢占彼此已预留的额度。次数不是实际费用，按任务开始的 UTC 日期归属。

自由讨论至少需要两位启用伙伴。发送前展开「讨论设置」，默认 3 轮、最多 30 次模型调用，可勾选「不限轮数」。一轮按参与人数次发言计算，例如五位伙伴的 3 轮最多 15 次发言，定向接话可能让同一位多次发言，失败位次也计入轮数。工具后续请求可能增加调用次数。

运行中点击「调整讨论」，可随时增加或减少轮数、改为不限轮数、修改本次调用上限或关闭「所有伙伴暂无补充时结束」。下一次发言／模型请求前生效；调低到已使用数量以下会停止后续请求，不撤回已发请求。修改当前任务不改变 LINE 下次任务的默认配置。

自由讨论仅为下一次发言预留最多 1–3 次调用，未用部分释放。达到轮数、单次调用上限、每日额度，或所有伙伴明确无补充（可选）、连续三次重复／失败、权限变更时结束；也可随时点击「停止」。不限轮数仍保留有限调用上限，不是无限费用授权。服务重启后不自动续跑。消息会显示轮次、发言序号和接话关系。

## 开发工作台

“共同开发”共享一个项目；“独立开发”让每位伙伴通过工具只访问自己的分支。网页用户能比较分支，把选中文件提出合并到共享项目。

推荐：“请先读取项目，制作一个简单的待办页面，提交文件变更到项目工作台，等我批准。”

1. 伙伴读取文件和版本，提交待审查提案。
2. 创建者或管理员查看差异并批准/拒绝。
3. 批准时原子保存整组文件；任一版本冲突就全部不保存。
4. 导出 ZIP，在自己的开发环境检查、运行和测试。

手工新增、编辑、导入也需要审查。每分支最多 100 文件、100 万字符；单文件 3 万字符，每提案最多 12 文件、8 万字符。删除保留版本标记，防止旧提案覆盖。批准不执行代码。

## 公司内部试用

邀请少量同事，先测试会议复盘、文稿对比、开发提案。所有者/管理员管配置、成员、审计；普通成员可参与团队群；只读成员不能调用模型或改内容。私有群仅创建者可经应用访问，管理员角色也不能读取别人私有群；服务器运维仍可读数据库和备份，不是端到端加密。企业知识检索、SSO、部门策略和业务系统写入未提供。

## 连接真实 LINE 群

需要你自己的 LINE Official Account 与 Messaging API channel。

1. 从 LINE Developers 获取 Channel secret 和 Channel access token，在「设置 → LINE 连接」保存、验证，核对账号后启用。
2. 复制页面的 HTTPS Webhook URL 到 LINE Developers，开启 Use webhook。本机 localhost 不能直接被 LINE 访问。
3. 在 channel 设置允许加入群聊，按需关闭重复自动应答，把官方账号邀请到目标群。
4. 网页目标群点击“连接群聊”，生成 10 分钟有效的绑定码。在 LINE 群发送 `/绑定 绑定码`。
5. 回网页核对群名、默认模式及共享范围后确认。默认只读取本次绑定之后的 LINE 对话，不读取网页消息。笔记和项目默认不开放；明确勾选后，**整个 LINE 群可通过工具访问本群全部笔记和项目，包含绑定前资料**。页面会列出现有资料数量，建议为 LINE 单独新建群。
6. LINE 发 `/af 你好` 或 `/af @小文 帮我润色这句话`。网页会同步显示这一轮。

LINE 显示一个官方账号，使用不同伙伴发送者名称，不是多个独立账号。普通消息不会进入本应用存储或触发模型；只有 `/af`、`/家族`、`/绑定` 指令被处理，LINE 平台本身仍可能处理消息。网页普通发言不会自动推送到群，只有 LINE 发起的轮次结果回传。

快回复使用 Reply；慢任务先确认正在处理，完成后用 Push。Push 受 LINE 套餐、群接收人数等影响，模型次数限制不是 LINE 费用限制。发送不确定时不自动重发，网页保留回答。仅回传最后实际轮次的完整回答；失败或取消用系统提示，不混入第一轮凑数。一次最多五条，完整讨论在网页查看。

LINE 默认各自回答；管理连接中可独立选择默认聊天方式，/af 空指令显示当前模式。网页发送框的临时选择不改 LINE 设置。LINE 每空间默认每日 40 次模型调用，同时受空间总额度约束，可由部署配置调整。

LINE 可选择「自由讨论」并保存默认轮数和调用上限。群成员可发送 `/af 状态`、`/af 停止`、`/af 轮数 5`、`/af 轮数 无限制`、`/af 额度 30`，控制本绑定从 LINE 发起的当前讨论；不能控制网页发起的任务。修改默认配置只影响下次任务。自由讨论结束后发送结束原因和最近四条完整发言，全部过程保留在网页，不逐条刷屏。

更改资料共享开关会重置 LINE 可用上下文并使旧任务失效，防止撤权后从先前回答读出资料。更改默认模式不会清空记录。网页可解除绑定，管理员可停用连接。收到签名有效的机器人离群事件会自动解绑。LINE 用户不能批准代码、邀请网页成员或改管理设置。
