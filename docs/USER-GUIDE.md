# 使用与 LINE 接入

## 多伙伴聊天

名字、职责、模型分别配置。可以用同一个模型扮演不同岗位，也可以混用 GPT、Claude、Gemini。每条回答显示配置的实际模型名。读取到服务商模型列表不等于真实调用成功。

- **各自回答**：伙伴看同一个问题分别回答，最多三位并发。
- **一起讨论**：第一轮提出观点，第二轮阅读第一轮结果并回应，最多两轮。
- **指定一位**：选择一位伙伴；也可输入 `@小文`，后加空格或标点。
- **停止**：取消生成，阻止后续轮次与工具写入。已发给模型的请求可能仍计费。

Enter 发送，Shift + Enter 换行；中文输入法选字不会误发。未发送文字仅保存在当前浏览器会话，退出登录清除。附件支持文本和代码，作为消息发给模型；不解析图片、PDF、音视频。启用工具的伙伴可按需读取本群笔记；没有任意浏览网页或读取电脑文件的能力。

## 开发工作台

“共同开发”共享一个项目；“独立开发”让每位伙伴通过工具只访问自己的分支。网页用户能比较分支，把选中文件提出合并到共享项目。

推荐：“请先读取项目，制作一个简单的待办页面，提交文件变更到项目工作台，等我批准。”

1. 伙伴读取文件和版本，提交待审查提案。
2. 创建者或管理员查看差异并批准/拒绝。
3. 批准时原子保存整组文件；任一版本冲突就全部不保存。
4. 导出 ZIP，在自己的开发环境检查、运行和测试。

手工新增、编辑、导入也需要审查。每分支最多 100 文件、100 万字符；单文件 3 万字符，每提案最多 12 文件、8 万字符。删除保留版本标记，防止旧提案覆盖。批准不执行代码。

## 公司内部试用

邀请少量同事，先测试会议复盘、文稿对比、开发提案。所有者/管理员管配置、成员、审计；普通成员可参与团队群；只读成员不能调用模型或改内容。私有群仅创建者可经应用访问，管理员角色也不能读取别人私有群；服务器运维仍可读数据库和备份，不是端到端加密。企业知识检索、SSO、部门策略和业务系统写入未提供。

## 连接真实 LINE 群

需要你自己的 LINE Official Account 与 Messaging API channel。

1. 从 LINE Developers 获取 Channel secret 和 Channel access token，在「设置 → LINE 连接」保存、验证，核对账号后启用。
2. 复制页面的 HTTPS Webhook URL 到 LINE Developers，开启 Use webhook。本机 localhost 不能直接被 LINE 访问。
3. 在 channel 设置允许加入群聊，按需关闭重复自动应答，把官方账号邀请到目标群。
4. 网页目标群点击“连接群聊”，生成 10 分钟有效的绑定码。在 LINE 群发送 `/绑定 绑定码`。
5. 回网页核对群名，勾选共享范围后确认。**LINE 群内所有成员都能发指令，现有网页历史、笔记、项目资料可能进入模型回答。** 旧历史不会逐条推送，但仍可能被问到。建议为 LINE 单独新建群。
6. LINE 发 `/af 你好` 或 `/af @小文 帮我润色这句话`。网页会同步显示这一轮。

LINE 显示一个官方账号，使用不同伙伴发送者名称，不是多个独立账号。普通消息不会进入本应用存储或触发模型；只有 `/af`、`/家族`、`/绑定` 指令被处理，LINE 平台本身仍可能处理消息。网页普通发言不会自动推送到群，只有 LINE 发起的轮次结果回传。

快回复使用 Reply；慢任务先确认正在处理，完成后用 Push。Push 受 LINE 套餐、群接收人数等影响，模型次数限制不是 LINE 费用限制。发送不确定时不自动重发，网页保留回答。每轮最多回五条，完整讨论在网页查看。

网页可解除绑定，管理员可停用连接。收到签名有效的机器人离群事件会自动解绑。LINE 用户不能批准代码、邀请网页成员或改管理设置。
