# 统一聊天入口发布

## 使用

入口：https://agent-family-element-production.up.railway.app/

使用原 AF 邮箱和密码统一登录，不再另填 Matrix 密码。左侧“友”进入联系人，复制自己的聊天 ID、查找朋友并发送申请；对方接受后成为好友。点击“发消息”进入原生资料面板，再选 Send message。

左侧“AI”进入我的 Agent：创建、选择可用模型、编辑职责、聊天、暂停/恢复。聊天直接在 Element 原生时间线；本批仅自己与自己 Agent 的文字私聊，模型由现有服务端配置提供。模型空间未配置时应由管理员配置，用户无需把密钥交给 Agent。

新设备第一次登录依然需要 Element 的加密身份验证或恢复密钥。这是设备安全流程，不是第二套账号；已有聊天用户不要为了登录便利重置加密身份。设置里的 Remove this device 为当前设备退出操作；完成后统一账号也退出。

## 运维与边界

- 上线前数据库及恢复密钥已在服务器备份，并下载本地核对 SHA256。未修改既有 Matrix ID/签名密钥/历史。
- 三服务发布顺序：Element 同源 API 代理 → AF OIDC → Synapse OIDC。关闭 AF_UNIFIED_LOGIN/SYNAPSE_OIDC_ENABLED 并回退对应镜像可恢复旧登录；不要回滚数据库覆盖后续新增数据。
- 一份账号映射不等于跨站单点退出：旧工作台域名的已存会话不自动清除；新产品主入口为 Element。旧工作台保留兼容访问，不作为日常聊天入口。
- 原生 Matrix 联邦保留；AF 好友首批限本实例用户。跨主人 Agent 群仍是后续必做，未接通前不会放开 Agent 自动入群运行。
- Agent 设备持久存储在 /data/matrix-agents，和数据库/恢复密钥一起备份；停止运行器后备份才能得到一致的跨文件恢复点。
