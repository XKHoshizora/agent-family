## 审查

8 步各自通过独立审查，其中决定谁回复、什么时候去判断、网页设置各返工一到两轮。整体审查结论是“没有严重问题，可以按默认关闭部署”，并指出三处应在有人使用前修好；这三处和所有小问题都在清理轮里修掉了，清理轮又经过一次复查和一小轮收尾。

审查查出并修好的主要问题：

- 两次判断同时进行时可能互相卡死（实现者复现出了真实的数据库死锁，改成统一的加锁顺序）。
- 连续第二次主动回复时，门槛的回落少算了“别人说了几句话”这一部分。
- 按“让 Agent 停下”之后，已经排队或正在写的主动回复不会停。
- 一条还在排队的主动回复被 @ 接管后，仍被当作“主动回复”计费和处理。
- 发消息时多了一次数据库查询，所有带 @ 的消息都变慢。
- 主动回复失败时（比如主人点数用完），全群会看到“××暂时无法回复”。
- 主动回复排队之后不再检查额度和开关：同一个 Agent 在几个群同时被选中会超支；主人关掉开关后已排队的仍会发出。
- 一个账号可以把全站每天的判断次数用光。

## 局限

- 门槛是用 97 段手写的群聊校准的，不是真实群聊。朋友试用后要用真实群聊再校准一次。
- 20 个以上 Agent 同时开着主动参与的群没有测到。
- “没人叫你”那段提示目前用的是“朋友式”写法，是我按对比结果暂定的，等产品负责人挑选。
- 整件事依赖一个判断模型；它出错、超时或被改动时，主动回复就停（被 @ 不受影响）。
- （2026-11-19 已改）“该谁接话”仍然只针对最新的一条消息；“有没有人让它安静”改成针对上次判断之后的所有新消息，所以被后面的消息盖掉的“别插话”也会被判断到，已经判断过的不会再算一次。新消息超过 15 条时只看最近 15 条。
- 调度记在服务的内存里（单实例）：服务重启会丢掉最近 3 秒内待判断的消息，后果是那一次没人主动回复。

## 实施中替产品负责人做的决定（每条附改回来的代价）

设计上的：

1. 每条消息只调用一次判断模型，让它在所有开了主动参与的 Agent 和“没人”之间选一个（产品负责人提出，实验验证后采用）。代价：退回逐个问的写法要改“决定”这一步。
2. 被判断为“让它安静”的那条消息，它不许开口，无论它在“选谁”里得分多高。代价：一个配置数字（0.3）。
3. 得票最高的 Agent 如果说不了话（额度用完、正在写别的回复、撞了保险丝），这次没人回复，不找第二名。代价：改一处判断。
4. 判断模型的回答只要缺了任何一个选项，或者概率加起来明显不等于 1，就当作没有答案。代价：极少数情况下少回一次。
5. 一个群里所有被判断的 Agent 看同一段聊天记录：只包含最晚进群那个之后的消息。刚进群的 Agent 不会被叫去回答它进群之前的消息。
6. 最多 253 个 Agent 同时作为选项（判断模型一次最多 254 个选项，留一个给“没人”），超过时轮流。
7. “没人叫你”的提示暂用“朋友式”写法；主动回复时不再对模型说“有人 @ 你才回复”那句。

数字上的（都是站点配置，可不改代码调整）：

8. 门槛：少说 0.80、适中 0.65、多说 0.50；每主动回复一次抬高 0.10，最多 0.25；每 2 分钟或别人每说 4 句减半。
9. 委婉让它安静抬高 0.15、10 分钟减半；直说抬高 0.33、1 小时减半；门槛上限 0.98。
10. 保险丝：每个 Agent 每个群 10 秒 1 次、每小时 30 次。
11. 同时进行的判断最多 8 个，多的排队。
12. 每个群每小时最多 600 次判断、每个人每小时最多 300 次（只算真正调用了判断模型的）。
13. 全站每天最多 10 万次判断（验收环境的配置值；代码默认 2 万）。
14. 等对方停下 3 秒再判断；给判断模型看最近 15 条消息，每条最多 300 个字；上次判断之后的消息前面标【新】（2026-11-19 加）。

行为上的：

15. 主动回复的每日额度用完、撞上保险丝或主人的频率上限时，静默不回，群里不提示。“额度用完时主人收到一次提醒”仍然是 Agent 页面上的一行字，不是消息推送（和别人 @ 的额度一样，等消息通知那一批再接）。
16. 一条还在排队的主动回复，如果这时有人 @ 了这个 Agent，它就变成那个人叫的回复：按那个人的额度和限次算，不再带“主动回复”标记。
17. 按“让 Agent 停下”会取消排队中的主动回复、打断正在写的；被人 @ 接管的不受影响。
18. 主动回复开始写之前再查一次开关和额度，不该写就悄悄取消。
19. 主动回复失败时不向群成员显示任何东西，主人照常能看到失败。
20. 站点没有配置判断模型时，网页上不显示这个开关；已经开着的 Agent 只显示开关本身，可以关掉。
21. 成员的 @ 并进一条排队中的回复时，不受“每人每分钟 5 次”的限制（上一批就是这样），仍受主人的频率上限和额度约束。
