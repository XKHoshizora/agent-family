# 主动回复时那句说明的几种写法：并排对比

生成时间：2026-11-18 19:46（UTC）。同一段群聊、同一个 Agent、同一个模型，只换“没人叫你”那段说明。人格设定都只有一句“说话自然、友好”，所以差别主要来自这段说明。

| 写法 | 内容 |
|---|---|
| A 规则式 | 没有人 @ 你。你是看到相关的话题主动发言：简短、有用，不要寒暄。 |
| B 处境式 | 群里没有人叫你。你是自己看到这个话题、觉得能帮上忙才开口的，就像群里一个懂行的朋友顺口接一句。直接说有用的，不用打招呼，也不用解释你为什么出现；拿不准就少说。 |
| C 朋友式 | 这次没有人点你的名。你就是这个群里的一员，刚好懂这个，像平时聊天那样自然地接一句话就行：一两句，口语，不用客套，也别像客服或者写报告。别人没问的不用展开。 |
| D 不加说明 | （什么都不加） |

- **A 规则式**（160 字）：西红柿炒鸡蛋最快，清淡的话少放糖和油就行。 ⏎ 做法： ⏎ 1. 西红柿切块，鸡蛋打散加一点盐。 ⏎ 2. 鸡蛋炒到半凝固盛出。 ⏎ 3. 锅里少油，西红柿炒出汁，加少许盐（想更清爽可以加点水煮一会儿）。 ⏎ 4. 倒回鸡蛋翻匀，撒点葱花就能出锅。 ⏎ 想更清淡的话，可以加个番茄蛋花汤：西红柿煮软后淋入蛋液，撒点葱花和胡椒粉，十分钟搞定。
- **B 处境式**（113 字）：西红柿炒蛋就行，清淡又快。 ⏎ 鸡蛋打散加一点点盐，先炒到半凝固盛出来。锅里再放少许油，西红柿切块炒出汁，加少量盐和一点糖提鲜，把蛋倒回去翻匀就好，大概五六分钟。 ⏎ 想更清爽，可以加点葱花；要是家里有豆腐或者青菜，加进去也很搭。
- **C 朋友式**（59 字）：西红柿炒蛋就行，清淡又快，十分钟搞定。鸡蛋炒至七成熟盛出，西红柿切块炒出汁，加点糖，再把蛋倒回去翻匀，出锅前撒点葱花。
- **D 不加说明**（132 字）：西红柿炒鸡蛋最简单，清淡的话可以少放油、少盐，西红柿先炒出汁再下鸡蛋，口感更嫩。 ⏎ 还可以做个西红柿鸡蛋汤：水烧开后放切块的西红柿煮两三分钟，倒入打散的蛋液，轻轻搅出蛋花，加点盐、葱花或几滴香油就行，十分钟搞定，很适合晚上吃。 ⏎ 小林今天辛苦了，好好吃饭休息一下。
