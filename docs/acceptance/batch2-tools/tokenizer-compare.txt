# 三家模型实际计费的输入 token，对比我们的量法（2026-11-20）。方法：同一段文字加在一句固定的话后面发给模型，取两次“输入 token”之差。
# DeepSeek 走官方接口；OpenAI 系和 Anthropic 系走验收环境使用的中转。脚本 .claude/tokenizer-compare.mjs（不进仓库）。

每类文字：字符数 / 字节数 / 我们的量（字节÷3）；各家实际计费的输入 token，括号里是 token÷量 和 token÷字节
